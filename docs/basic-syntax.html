R 语言编程：基于 tidyverse

第 1 基础语法

本章严格沿用教材第 1 章的知识顺序：先建立可复现的 R 工作环境，再学习数据结构、字符串与日期时间、正则表达式、控制结构和函数。与“记住所有函数”相比，本章更重要的目标是建立一套稳定的判断框架：对象是什么类型、具有怎样的结构、函数接收什么输入、返回什么输出，以及怎样把一次操作推广到一组数据。

教材主线：基础语法是载体，向量化、函数式编程和数据思维才是贯穿全章的核心。

本章学习目标

完成本章后，你应当能够：

  1. 在 R Project 中组织脚本、数据和输出，并从干净会话重现分析；
  2. 根据数据是否同质、维数多少，选择向量、矩阵、数组、列表、数据框或因子；
  3. 正确使用 [ ]、[[ ]] 与 $ 提取对象；
  4. 用 stringr、正则表达式和 lubridate 处理常见文本与日期时间；
  5. 在分支、循环、向量化和 purrr::map_*() 之间作出合理选择；
  6. 按“输入—处理—输出—验证”的契约设计自定义函数。

建议的学习方法：每段代码都先预测结果，再运行；遇到错误时先检查 class()、typeof()、length()、dim() 和 str()。

1.1.1.1 首次设置的原则

  • 文件编码使用 UTF-8；
  • 不在启动时自动恢复 .RData，退出时不自动保存工作区；
  • 每个分析使用独立的 R Project；
  • 重要对象由脚本生成，重要结果明确写入文件；
  • 需要复现时，重启 R 后从第一行重新运行。

教材介绍了通过 setwd() 改变工作目录的方法。它适合临时诊断，但课程项目中优先使用 Project 根目录 + 相对路径。这样项目移动到另一台电脑后仍可运行。

Code 
basename(getwd())
#> [1] "book"
file.path("data", "scores.csv")
#> [1] "data/scores.csv"

1.1.2 常用操作

1.1.2.1 扩展包的生命周期

任务 常用方式 何时执行
安装 install.packages("pkg") 一台电脑通常一次
加载 library(pkg) 每个新会话一次
单次调用 pkg::fun() 无需加载整个包
更新 update.packages() 有计划地更新并重新验证项目
删除 remove.packages("pkg") 确认不再需要时
Code 
stringr::str_to_upper("R language")
#> [1] "R LANGUAGE"

安装和加载是两件不同的事。不要把 install.packages() 放进每次都运行的分析脚本；项目脚本只需要加载或用 :: 调用。

1.1.2.2 赋值与对象

R 同时支持 <- 和 =。课程代码使用 <- 给对象赋值，用 = 指定函数参数，使阅读时角色更清楚。

Code 
radius <- c(2, 4, 7)
area <- pi * radius^2
area
#> [1]  12.56637  50.26548 153.93804

对象名应表达含义。R 区分大小写，score 与 Score 是两个对象；对象名可以包含字母、数字、点和下划线，但不能以数字开头。

1.1.2.3 基本运算与比较

Code 
7 %/% 3
#> [1] 2
7 %% 3
#> [1] 1
2^5
#> [1] 32
c(1, 3, 5) %in% c(2, 3, 4)
#> [1] FALSE  TRUE FALSE

浮点数由有限位二进制数近似存储，因此不要把“打印出来相同”误认为内部值绝对相等。

Code 
0.1 + 0.2 == 0.3
#> [1] FALSE
all.equal(0.1 + 0.2, 0.3)
#> [1] TRUE
dplyr::near(0.1 + 0.2, 0.3)
#> [1] TRUE

&、| 对逻辑向量逐元素运算；&&、|| 只判断第一个元素，常用于 if 或 while 的单一条件。

1.1.2.4 基本数据类型与特殊值

R 的原子类型包括逻辑型、整数型、双精度数值型、字符型、复数型和原始型。实际数据分析最常见的是前四类。

Code 
x <- c(TRUE, FALSE, NA)
y <- c(1L, 2L, 3L)
z <- c(1.5, NaN, Inf)
txt <- c("R", "tidyverse")

tibble(
  object = c("x", "y", "z", "txt"),
  class = c(class(x), class(y), class(z), class(txt)),
  typeof = c(typeof(x), typeof(y), typeof(z), typeof(txt))
)
值 含义 常用判断
NA 缺失或未知 is.na()
NaN 未定义的数值结果 is.nan()
Inf, -Inf 正、负无穷 is.infinite()
NULL 对象或成分不存在 is.null()
Code 
mean(c(80, NA, 90))
#> [1] NA
mean(c(80, NA, 90), na.rm = TRUE)
#> [1] 85
NA == NA
#> [1] NA
is.na(NA)
#> [1] TRUE

NA == NA 的结果仍是 NA，因为“一个未知值是否等于另一个未知值”不能确定。检测特殊值要使用相应的 is.*() 函数。

1.1.2.5 保存、载入与清理

Code 
saveRDS(area, "output/area.rds")
area_again <- readRDS("output/area.rds")

write_csv(tibble(radius, area), "output/circle_area.csv")
circle_area <- read_csv("output/circle_area.csv")

课程推荐保存“明确命名的数据或结果”，而不是保存整个工作区。清空环境并不能修复不可复现的代码；更可靠的做法是重启 R，然后运行完整脚本。

阅读帮助页时依次看：Usage（调用形式）、Arguments（参数）、Value（返回值）、Examples（示例）。遇到函数同名时使用 包名::函数名()，如 stats::filter() 与 dplyr::filter()。

1.2 数据结构：向量、矩阵、多维数组

向量、矩阵和数组都要求元素类型一致，区别主要在维数。

结构 维数 类型是否一致 典型创建函数
原子向量 1 是 c(), seq(), rep()
矩阵 2 是 matrix()
数组 2 维以上 是 array()

1.2.1 向量（一维数据）

1.2.1.1 创建与向量化运算

Code 
x <- c(2, 4, 6, 8)
seq(from = 0, to = 1, by = 0.25)
#> [1] 0.00 0.25 0.50 0.75 1.00
rep(c("A", "B"), times = 2)
#> [1] "A" "B" "A" "B"

x + 1
#> [1] 3 5 7 9
x * c(1, 10, 100, 1000)
#> [1]    2   40  600 8000

R 的许多函数天然接收向量并逐元素工作，这就是向量化。较短向量参与运算时可能被循环补齐（recycling）；除非这种对应关系十分明确，否则应避免依赖隐式循环补齐。

Code 
1:6 + c(10, 20)
#> [1] 11 22 13 24 15 26

1.2.1.2 逻辑向量与筛选

Code 
score <- c(58, 76, 91, NA, 84)
passed <- score >= 60
passed
#> [1] FALSE  TRUE  TRUE    NA  TRUE
score[passed & !is.na(passed)]
#> [1] 76 91 84

== 是逐元素比较；%in% 判断左侧每个元素是否属于右侧集合，尤其适合多个候选值。

Code 
major <- c("统计学", "经济学", "数据科学", "数学")
major %in% c("统计学", "数据科学")
#> [1]  TRUE FALSE  TRUE FALSE

1.2.1.3 字符向量与类型转换

1.5 正则表达式

正则表达式用模式概括一组字符串。处理任务通常分为四步：发现规律 → 写出模式 → 在小样本上查看匹配 → 提取或替换。

1.5.1 基本语法

类别 符号 含义示例
位置 ^, $ 字符串开头、结尾
任意与选择 ., | 任意字符、二选一
字符集合 [abc], [^abc] 集合内任一字符、集合外字符
重复 *, +, ?, {n,m} 0 次以上、1 次以上、可选、限定次数
字符类 \\d, \\s, \\w 数字、空白、单词字符
分组 ( ) 组合、捕获和控制优先级

R 字符串本身也使用反斜线转义，因此正则中的 \d 在 R 代码里通常写成 "\\d"。

Code

ip_location <- c(
  "175.10.237.40(湖南-长沙)",

1.6.2 循环结构

教材把循环迭代分为三个层次：显式循环、apply 函数族和 purrr 泛函式。它们不是互相排斥的“新旧语法”，而是对不同问题的表达工具。

1.6.2.1 for 循环：看见迭代的三个部件

Code 
numeric_iris <- as_tibble(iris[1:4])
output <- vector("double", ncol(numeric_iris))
for (i in seq_along(numeric_iris)) {
  output[[i]] <- mean(numeric_iris[[i]])
}
names(output) <- names(numeric_iris)
output
#> Sepal.Length  Sepal.Width Petal.Length  Petal.Width 
#>     5.843333     3.057333     3.758000     1.199333

一个稳定的 for 循环包含：预先分配的输出、迭代序列、循环体。不要在每次循环中用 c() 或 rbind() 不断扩大对象；先保存到预分配向量或列表，最后一次合并。

1.6.2.2 while 与 repeat

Code 
set.seed(123)
x <- -Inf
draws <- 0L
while (x <= 1) {
  x <- rnorm(1)
  draws <- draws + 1L
}
c(draws = draws, last_value = x)
#>      draws last_value 
#>   3.000000   1.558708

while 适用于迭代次数未知、先判断再执行；repeat 至少执行一次，必须设计清晰的 break 条件。next 跳过当前一轮，break 结束整个循环。

1.6.2.4 purrr 泛函式迭代

泛函式是“以函数作为输入的函数”。map(.x, .f) 把同一个函数 .f 映射到序列 .x 的每个元素，并收集结果。

Code

#>     5.843333     3.057333     3.758000     1.199333

选择后缀就是声明输出契约：map_lgl() 返回逻辑向量、map_int() 返回整数向量、map_dbl() 返回双精度向量、map_chr() 返回字符向量，map() 返回列表。

Code 
list(c(1, 2, NA), c(4, 5, 6)) |>
  map_dbl(\(x) mean(x, na.rm = TRUE))
#> [1] 1.5 5.0

height <- c(1.58, 1.76, 1.64)
weight <- c(52, 73, 68)
map2_dbl(height, weight, \(h, w) w / h^2)

score_to_grade <- function(score) {
  if (length(score) != 1L || is.na(score)) {
    return(NA_character_)
  }
  if (score < 0 || score > 100) {
    stop("score 必须位于 0 到 100 之间")
  }
  if (score >= 90) {
    "优"
  } else if (score >= 80) {
    "良"
  } else if (score >= 70) {
    "中"
  } else if (score >= 60) {
    "及格"
  } else {
    "不及格"
  }
}
score_to_grade(86)
#> [1] "良"

如果一个函数有多个返回结果，应组合成一个有名字的列表或数据框。

Code 
mean_sd <- function(x, na.rm = FALSE) {
  list(
    mean = mean(x, na.rm = na.rm),
    sd = sd(x, na.rm = na.rm),
    n = sum(!is.na(x))
  )
}
mean_sd(c(2, 6, 4, 9, 12))
#> $mean
#> [1] 6.6
#> 
#> $sd
#> [1] 3.974921
#> 
#> $n
#> [1] 5

默认参数表达最常见的用法；... 用于把额外参数传给另一个函数，但应谨慎，避免参数去向不清。

Code 
summarise_num <- function(x, ...) {
  c(mean = mean(x, ...), sd = sd(x, ...))
}
summarise_num(c(1, 2, NA, 4), na.rm = TRUE)
#>     mean       sd 
#> 2.333333 1.527525

本章小结

  • 数据结构决定了可以怎样索引、计算和迭代；
  • [ ] 保留容器，[[ ]] 或 $ 通常取出成分；
  • 字符串、日期时间和因子不是“显示格式”，而是具有明确语义的数据类型；
  • 分支负责选择路径，循环负责重复，函数负责封装；
  • map()、map2()、pmap() 分别对应一元、二元和多元函数式迭代；
  • 可复现项目依赖脚本和明确输入，不依赖控制台历史或自动保存的工作区。
